# 扩展模拟场景 v1

33 组离线工程回归用例，输入、预期结果、场景配置可直接查看 [cases.json](cases.json)。实际运行汇总见 [report.json](report.json)，本轮 33/33 通过。

数据为 AI 根据现有业务规则编写的合成样本，`human_reviewed: false`。预期费用、耗时和状态在执行前写入，并非从运行结果自动反填。结构参考 [Langfuse 数据集指南](https://langfuse.com/academy/datasets)，分为 `input`、`expectedOutput` 和 `metadata`；没有上传到 Langfuse。

## 覆盖范围

| 类别 | 数量 | 代表用例 |
| --- | ---: | --- |
| 输入校验 | 8 | 同时缺三项、空白主题、负预算、三位小数、布尔预算、NaN、非法日期、缺主题 |
| 预算边界 | 4 | 0、4.99、5.00、5.01 元 |
| 时间边界 | 4 | 已过期、恰好到期、差 1 秒、恰好 540 秒 |
| 输入规范化 | 3 | 数值预算、UTC 时间、无时区时间及主题空白 |
| 工具故障 | 9 | 四工具分别首次失败、脚本连续失败两次、持续失败、四工具组合故障 |
| 超预算重规划 | 3 | 高规格 12 元恰好可行、降配后 8 元恰好可行、7.99 元不足以重写 |
| 素材不足 | 1 | 空检索结果后停止 |
| 执行上限 | 1 | 循环检索在 12 次执行后停止 |

注意：`incomplete` / `needs_input` 是部分用例的正确预期；“通过”表示符合该用例的预期，不代表任务均生成了方案。持续保存失败的用例仍有 5 元估算总费用，但没有已保存方案。

## 运行

在项目根目录执行，无需 API Key，不访问模型网络接口：

```bash
uv run python scripts/run_synthetic.py
uv run pytest tests/test_synthetic.py -q
```

默认导出到新的 `.runs/synthetic-<时间戳>/`，可用 `--destination` 指定新目录。已有目录会被拒绝，避免覆盖证据。每个用例包含原始定义 `case.json`、实际 `output.json`，以及 `evidence/` 下的任务快照、Trace、工具结果和已保存方案。

本轮完整证据在本地 `.runs/synthetic-expanded-v1/`（Git 忽略）；仓库只收录用例和紧凑汇总。重新运行即可生成完整证据，随机 ID 和真实事件时间会变化，业务费用、模拟耗时及终态应一致。

验证包括终态及原因、调用次数、累计费用、耗时、账本一致性、故障注入是否生效、执行上限，以及成功方案是否实际落盘并符合预算和截止时间。33 组用例也直接接入 pytest；另有 2 项验证器测试检查错误预期能否被识别、历史证据是否禁止覆盖。

## 适用边界

这些用例复用现有 `OfflineMockClient` 的春季素材与固定脚本策略。金额和时间预期只适用于当前定价、耗时表及 Mock 策略；它们不是 DeepSeek 决策能力、跨行业素材召回或文案质量的验收标准。真实模型仍使用原有 `examples/real/` 证据。脚本质量需另行人工评审；本数据集未将合成文案标为人工认可的标准答案。
