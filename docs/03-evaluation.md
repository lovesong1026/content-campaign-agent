### 超预算路径

检索 → 高级素材与 premium 初稿 → 估算总费用 12 → 新的模型响应选择基础素材及 economy → 改写后估算 8 → 模型额外估算一次，费用增加到 9 → 保存。

额外估算实际发生，增加 1 单位和 1 分钟，未从记录删除。不能将此路径描述成“最终以 8 保存”。模型能根据观察调整，但仍可能产生冗余调用。

预算和时间不可行路径也没有在第一轮立即停止：模型先检索、生成，再依据观察或门禁结果结束。已有费用和成功脚本均保留，未取得估算时方案费用保持未知。这些路径满足未完成及状态一致的要求，但说明提前识别不可行性还有改进空间。

### 工具失败路径

首次脚本生成注入可恢复故障，计费 2、耗时 5 分钟；此前检索状态保持成功。下一轮模型选择重新生成，随后估算、保存。业务执行器没有自动重试，Trace 可核对观察及后续模型响应的轮次。

### 内容与实际 API 用量

AI 检查了归档脚本的字段、引用、规格和基本主题相关性；尚未进行独立人工质量评分。内容围绕合成材料中的自然光、桌面及日常场景展开，不代表商业投放效果。

正常、超预算及失败路径的 token 合计分别为 19,454、51,009、26,598，来自各自 `model_response.usage`，包含规划和脚本请求。缓存等计价因素不同，不能仅据总数推断货币费用；未查询真实账单，实际金额保持未知。

### 显式续跑与费用缺口补充

新增两项能力：在未取得估算时输出可计算的最低总费用与预算缺口；通过独立 `resume` 命令续跑失败、取消或中断的任务，不改变普通 `run` 的幂等行为。

续跑补充时全量 **126 项通过**，见 [当时 JUnit](../examples/resume/test-results.xml)。新增测试覆盖：

- 预算为 0、3、4、4.99 时正确给出总费用下界 5 及对应缺口，实际方案费用及总费用仍为未知。
- 四个工具分别失败后，在新 Agent 实例中只执行剩余步骤，保留原成功结果、失败记录、账本和耗时；续跑首轮模型能读取真实历史观察。
- 规划接口失败、生成中断、原材料/价格/费用/耗时/场景快照、旧任务快照兼容、同 ID 并发续跑和成功任务重复续跑。
- 预算、模拟时间及累计执行上限不重置；任务不存在、输入不足或模式不符不启动续跑。
- 保存已落盘但终态快照写入失败时，核对完整交付文件后恢复成功，不再请求模型、保存或收费；缺少文件可发起新保存尝试，文件损坏或内容冲突则停止且不覆盖。
- 续跑启动快照写入失败或只完成部分写入时，同一 Agent 实例不会卡在虚假的运行态；普通工具结果导出中断后，重启复用权威快照中的成功观察，不重复执行或收费；多次续跑继续累计历史与上限。
- CLI 子进程完成“读取失败任务 → 显式续跑 → 再次续跑只复用”的完整路径。

本轮只使用离线受控模型及临时目录，不调用真实 DeepSeek 或上传 Langfuse，不将工程测试通过计作真实模型成功率提高。旧真实模型、Mock 与 TodoList 归档均未覆盖或改写。使用方式与未知结果边界见 [续跑说明](07-todolist.md#显式续跑)。

## 5. 限制

- 本次真实模型样本不等于大规模成功率；模型别名的后端可更新，路径与内容有变动性。
- 超预算场景在用户主题中要求先生成高规格初稿并实际估价，以触发观察；没有强制执行器选择高价或预写日志。一般输入可能直接选便宜方案。
- 全量历史与重复状态摘要增加 token；本次出现额外估算，尚未做上下文压缩或冗余调用优化。
- 仅生成方案，不执行真实内容制作、发布或授权核验；素材均为合成数据。
- 单输出目录只支持一个写进程，其内部支持任务并发。跨文件无数据库事务，异常中断可能留下未确认文件。
- 不自动续跑；强制终止不能保证收尾，显式续跑仅复用已确认结果，未知生成尝试重新执行仍计费，保存文件冲突需先核对。验证平台为 macOS，Linux 尚未独立实测，Windows 文件锁不支持。

证据导出只调整目录定位信息以便移植，不改写实际工具参数、返回、费用、事件及模型动作。重跑脚本默认使用新目录，既有证据不会被覆盖。
